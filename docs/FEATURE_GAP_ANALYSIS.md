## 一、竞品功能拆解

### 1. TradingAgents (TauricResearch) — 多智能体辩论框架

**分析师团队 (4类，各有专属工具集):**

| 分析师 | 工具 | FinanceCrew对标 |
|--------|------|-----------------|
| Fundamentals Analyst | 资产负债表/现金流/利润表/分析师评级/机构持仓/做空/分红拆股 | ✅ 基本面分析师(有) |
| Sentiment Analyst | StockTwits + Reddit 社交媒体情绪 | ⚠️ 情绪面(仅新闻,无社交) |
| News Analyst | 新闻 + 全球宏观 + 内幕交易 + 财报日历 + 市场环境 | ⚠️ 新闻面(无内幕/财报日历) |
| Market/Technical Analyst | 股价数据 + 技术指标 + 分红拆股 | ✅ 技术面分析师(有) |

**流程编排特色 (LangGraph):**
- **双层辩论机制**: Bull/Bear研究员多轮辩论 → Research Manager裁决; 然后 Aggressive/Conservative/Neutral 三方风控辩论 → Risk Judge裁决
- **反思机制 (Reflection)**: 交易结束后回溯评分(宏观/技术/价格行为/新闻流/情绪/基本面/整体推理/结果质量 8维度), 形成"可重复模式/隐藏错误/运气/教训"记忆库
- **记忆系统**: `FinancialSituationMemory` — 每个角色(bull/bear/trader/judge/risk)独立记忆, 跨周期积累经验
- **信号传播 (Propagation)**: 分析师结论向下游节点结构化传递

**数据源:** yfinance + Google News RSS + Alpha Vantage + FRED(宏观) + Polymarket

### 2. AI Hedge Fund (virattt) — 可回测的基金引擎

**信号源 (Alpha Models, 两类):**

*量化模型:*
- PEAD (Post-Earnings Announcement Drift) — 财报后漂移

*LLM投资者人设 (6位, 纯system prompt驱动):*
| 人设 | 投资风格 | FinanceCrew对标 |
|------|----------|-----------------|
| Warren Buffett | 长期持有, 护城河, 安全边际 | ✅ 可复刻 |
| Charlie Munger | 质量优先, 公允价格 | ✅ 可复刻 |
| Benjamin Graham | 深度价值, 安全边际至上 | ✅ 可复刻 |
| Peter Lynch | 合理价格成长(GARP) | ✅ 可复刻 |
| Stanley Druckenmiller | 集中押注转折点 | ✅ 可复刻 |

**核心架构特色:**
- **Fund as first-class entity**: 基金是持久化对象(mandate YAML), 可回测/模拟/实盘
- **统一管线 `run_cycle`**: 数据→分析师→组合→风控→执行→账本, 回测/模拟/实盘同一代码路径
- **策略组合 (4个预设)**: deep-value / earnings-drift / fundamental-ls / inflections
- **组合构建**: conviction-weighted混合 + 可选market-neutral(截面去均值)
- **风控**: 硬性限制(max_position_pct / max_gross_exposure) + clamp审计 trail
- **事件研究引擎**: 财报事件CAR(累积异常收益)分析, 市场模型 + bootstrap置信区间
- **持久化账本**: 每次运行写CycleRecord(持仓/现金/NAV/每条thesis)

**Roadmap规划方向:**
- 市场状态检测(HMM) / 动量 / 均值回归 / 统计套利
- 风险平价 / 动态资金分配(Millennium式)
- CPCV/PBO过拟合验证
- Cathie Wood / Michael Burry / Bill Ackman 等更多人设

## 三、优化建议（三类）

### 🅰 第一类：高价值缺失功能（按优先级排序）

#### 1. 条件选股器 ⭐⭐⭐⭐⭐
- **功能价值**: 全市场扫描筛选是量化交易者最高频需求。用户大哥(量化背景)必然需要"PE<15且ROE>15%且近20日涨幅<5%"这类多条件选股。这是同花顺日活最高的功能之一。
- **实现难度**: 中 — 后端用AKShare拉全市场快照 + pandas条件过滤; 前端条件构建器(下拉选指标+比较符+数值)
- **数据源可行性**: ✅ AKShare `ak.stock_zh_a_spot_em()` 全市场实时快照(PE/PB/市值/涨跌幅/换手率等20+字段一次性获取)
- **AI参与**: 否(纯筛选); 可选AI增强: "用自然语言描述选股条件" → LLM转结构化筛选

#### 2. 板块轮动 / 概念热度 ⭐⭐⭐⭐⭐
- **功能价值**: A股是板块/概念驱动市场(远比美股明显)。掌握"今天资金在炒什么"是短线和轮动策略的核心。东财的概念板块涨跌排行+资金流入是最被盯的数据。
- **实现难度**: 中 — AKShare有现成接口(`stock_board_concept_name_em`, `stock_board_industry_name_em`)
- **数据源可行性**: ✅ AKShare东财接口免费
- **AI参与**: 可选 — LLM总结"今日3大热点板块及龙头股"+轮动节奏判断

#### 3. 沪深港通(北向资金) ⭐⭐⭐⭐⭐
- **功能价值**: 北向资金被称为"聪明钱", 个股北向持股变化是A股最强资金面信号之一。机构必备。当前TODO未列但优先级应极高。
- **实现难度**: 小 — AKShare `stock_hsgt_north_net_flow_in_em` (北向净流入) + `stock_hsgt_individual_em` (个股持股)
- **数据源可行性**: ✅ 东财接口免费
- **AI参与**: 否; 可选LLM解读"北向连续3日净买入XX意味着什么"

#### 4. 智能诊股(轻量版千股千评) ⭐⭐⭐⭐
- **功能价值**: 深度投研太重(5分析师+辩论, 耗时数分钟)。需要一个30秒出结果的"一句话诊股": 综合评分 + 趋势/资金/基本面/技术面四维雷达图 + AI一句话点评。用户在浏览自选股时快速过一遍。
- **实现难度**: 中 — 评分模型(规则+加权) + 雷达图(Recharts) + LLM生成一句话
- **数据源可行性**: ✅ 已有数据源可计算所有维度
- **AI参与**: ✅ 是 — LLM生成自然语言点评(核心价值)

#### 5. 龙虎榜深度分析 ⭐⭐⭐⭐
- **功能价值**: 已有`get_lhb`数据但无分析页。游资席位追踪(赵老哥/章盟主等知名席位)、机构专用席位、营业部排行是A股短线核心。东财龙虎榜分析是游资圈标配。
- **实现难度**: 中 — 数据已有(tools.py), 需建分析页: 席位统计/上榜原因/次日表现回测
- **数据源可行性**: ✅ AKShare `stock_lhb_detail_em` / `stock_lhb_yyb_detail` (营业部统计)
- **AI参与**: 可选 — LLM"该股连续上榜+知名游资介入, 短期关注"

#### 6. 财报日历 + 事件研究 ⭐⭐⭐⭐
- **功能价值**: TODO已列第4优先级。财报前后涨跌统计是事件驱动策略基础。AI Hedge Fund的CAR(累积异常收益)引擎是可直接借鉴的亮点。
- **实现难度**: 中 — 财报日历(AKShare `stock_report_disclosure`) + 历史涨跌统计 + 可选CAR计算
- **数据源可行性**: ✅ AKShare免费
- **AI参与**: 可选 — LLM"该股近4次财报3次超预期, 财报前5日平均涨2.3%"

#### 7. 融资融券数据 ⭐⭐⭐
- **功能价值**: 融资余额变化反映杠杆资金情绪, 融券余额反映做空压力。A股特有的多空力量数据。
- **实现难度**: 小 — AKShare `stock_margin_detail_szse/sse`
- **数据源可行性**: ✅ 免费交易所数据
- **AI参与**: 否

#### 8. LLM投资者人设库 ⭐⭐⭐⭐ (差异化机会)
- **功能价值**: AI Hedge Fund最出圈的功能 — 用巴菲特/芒格/格雷厄姆的视角分析股票。FinanceCrew当前5分析师是按"面"分工(宏观/基本面/技术/情绪/资金), 可以增加按"投资风格"分工的人设分析师。用户可以选择"让巴菲特和格雷厄姆同时看这只票"。
- **实现难度**: 小 — 纯system prompt驱动(参考AI Hedge Fund源码), 复用现有数据工具
- **数据源可行性**: ✅ 复用已有数据层
- **AI参与**: ✅ 是 — 核心就是LLM人设推理

### 🅲 第三类：差异化亮点（FinanceCrew独有优势）

#### 1. A股原生的AI智能体平台 ⭐⭐⭐⭐⭐
- **独特性**: TradingAgents和AI Hedge Fund都是美股为中心(yfinance/Financial Datasets)。FinanceCrew是**唯一深度集成A股数据源(AKShare+东财+腾讯)的AI智能体投研平台**。
- **强化方向**: 把A股特色数据(龙虎榜/北向/融资融券/板块轮动)全部喂给AI分析师, 形成美股AI工具无法复刻的本土优势。
- **行动**: 这是最核心的差异化护城河, 应作为产品定位重点。

#### 2. 回测防过拟合体系 (业界领先) ⭐⭐⭐⭐⭐
- **独特性**: Walk-Forward + CPCV + PBO + IC评估的组合, **比AI Hedge Fund的Roadmap还超前**(他们这些功能标为⬜ Planned)。FinanceCrew在这点上是领先的。
- **强化方向**: (1) 把这套体系包装成"策略可信度评分"(防过拟合绿灯/黄灯/红灯) (2) 写技术博客/文档建立专业口碑

#### 3. 投资者人设 × A股本土化 ⭐⭐⭐⭐
- **独特性**: AI Hedge Fund的巴菲特/芒格人设只看美股10-K。FinanceCrew可以做人设的**A股版**: 巴菲特看茅台、格雷厄姆扫银行股、Druckenmiller盯新能源拐点。
- **价值**: 本土化人设是内容传播和用户粘性的强力抓手。

#### 4. 对话式量化 (AI × 回测) ⭐⭐⭐⭐
- **独特性**: 已有智能对话 + 回测系统, 但未打通。可以做"用自然语言描述策略 → AI生成回测代码 → 一键回测 → AI解读结果"的闭环。
- **价值**: 降低量化门槛, 这是聚宽等平台做不到的(他们是纯代码环境)。

#### 5. 多空辩论直播 ⭐⭐⭐
- **独特性**: 已有多空辩论机制。可以做"辩论过程实时流式展示", 像看分析师开会一样。增强趣味性和信任感。

## 六、总结

FinanceCrew当前在**回测防过拟合体系**上领先两个对标开源项目(Walk-Forward/CPCV/PBO已实现, 对手还在Roadmap)。核心机会在于:
